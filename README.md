# 🧮 Calculadora Freemium™ — Pague para ver o resultado

Uma calculadora simples desenvolvida com **HTML, CSS e JavaScript puro**, criada com um objetivo extremamente importante para a sociedade:

> **Cobrar para você descobrir quanto é 2 + 2.** 💸

Este projeto é apenas um **meme / projeto de humor**.
A calculadora funciona normalmente, mas quando o usuário tenta visualizar o resultado, uma tela de cobrança aparece como se fosse necessário pagar para desbloquear a resposta.

## 😂 Como funciona?

1. O usuário digita uma operação matemática.
2. Clica para calcular.
3. A calculadora processa o resultado normalmente.
4. Porém...
5. 💰 **Surge uma tela cobrando para liberar o resultado.**

Porque conhecimento matemático claramente deveria estar atrás de um paywall.

```text
Você calculou:

10 + 10

Resultado:
🔒 BLOQUEADO

Plano Premium necessário
para visualizar o resultado.
```

## 🚀 Tecnologias utilizadas

O projeto foi desenvolvido utilizando apenas:

* **HTML5**
* **CSS3**
* **JavaScript Vanilla**

Sem React.
Sem Vue.
Sem Angular.
Sem backend.

Apenas JavaScript puro e decisões questionáveis.


> **Observação:** obviamente esses planos não existem. É um meme. 😎

## ⚠️ Aviso

Este projeto possui finalidade **educacional e humorística**.

Nenhuma cobrança real é realizada e nenhuma informação de pagamento deve ser coletada.

A tela de pagamento faz parte apenas da brincadeira.
